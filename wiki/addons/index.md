# Add-on reference

The approved layering, migration rules and minimal example live in [Add-ons](../architecture/addons.md).
All compiled-in add-ons are always enabled; per-device switches and the Manage screen are retired.

<!-- wiki:children -->
- [Agent](agent.md): Agent chat, chat note type and range embeds, registered shell surfaces, settings and search.
- [Board](board.md): Database Board layout, using the shared board kit.
- [Database](database.md): Database note type, inline block, property implementations and database layouts.
- [Schedule](schedule.md): Schedule note type that makes notes from templates on a hub or desktop runner.
- [Search card](search-card.md): `query` block that shows the live results of a query.
