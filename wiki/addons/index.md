# Add-on reference

The approved layering, migration rules and minimal example live in [Add-ons](../app/addons.md).

<!-- wiki:children -->
- [Agent](agent.md): Optional agent chat, chat note type and range embeds, registered shell surfaces, settings and search.
- [Board](board.md): Optional database Board layout, using the shared board kit.
- [Database](database.md): Database note type, inline block, property implementations and database layouts.
- [Schedule](schedule.md): Optional schedule note type that makes notes from templates on a hub or desktop runner.
- [Kanban](kanban.md): Optional kanban notes with manually collected cards and compact embeds.
- [Search card](search-card.md): Optional `query` block that shows the live results of a query.
<!-- /wiki:children -->
