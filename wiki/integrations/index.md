# Integrations

<!-- wiki:children -->
- [Agent (BubblePaw)](agent.md): A BubblePaw agent embedded in the hub: vault tools, a QuickJS code tool, a live channel to every device, automations on schedules and vault events.
- [AI assistants](ai-assistants.md): Claude and ChatGPT use the vault over MCP; Ask AI and tasks assigned to Agent run on this computer or on the hub.
- [Agent memory](agent-memory.md): One memory for every project and agent, kept in the vault: how Claude Code memory works today, and a plugin that points it at the hub. (proposed)
- [scratch-cli](scratch-cli.md): Runs a desktop vault's AI tasks with the in-app agent, without the app's UI.
- [Sharing](sharing.md): The hub's signed-in web viewer, public or private share links (this version or live) with preview cards, and the app's Share popup.
- [Wiki import](wiki-import.md): The notes CLI's wiki import, retired 2026-10-20 as the repo-to-vault mirror.
